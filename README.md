# News Data Pipeline

## Features

- Fetches latest news using NewsAPI
- Performs sentiment analysis using VADER
- Stores processed news in PostgreSQL
- Saves raw API response as JSON
- Uploads raw JSON to Amazon S3
- Uses environment variables for secure configuration
- Modular project structure following software engineering best practices

## Tech Stack

- Python
- PostgreSQL
- AWS S3
- boto3
- NewsAPI
- VADER Sentiment
